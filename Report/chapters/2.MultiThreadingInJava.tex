\section{La Classe ``\texttt{Thread}''}
Il Linguaggio di Programmazione Java mette a disposizione nella sua Libreria standard la classe ``\texttt{Thread}'', la quale permette allo sviluppatore di implementare Programmi che diano luce a Processi non Sequenziali.
